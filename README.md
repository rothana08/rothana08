## 🧭 What I Actually Do

I don't build todo apps. I build the stuff small businesses run on:

- 🧾 **Accounting engines** — general ledger, FIFO inventory, VAT, journal entries that actually balance
- 🏪 **Point-of-sale systems** — sales, stock, expense mapping, end-of-day reports
- 🏠 **Rental management** — rooms, tenants, billing cycles, payment tracking
- 📱 **Android apps** — shipped one to Google Play, learned a lot about what *not* to do

2+ years in Laravel. Now going deep on **Spring Boot** to level up into enterprise-grade backends.
